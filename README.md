# موقع دردشة الي بالذكاء الاصطناعي 

موقع دردشة الذكاء الاصطناعي لكلية الخرمة التطبيقية هو تطبيق ويب يهدف إلى تسهيل تواصل الطلاب مع الكلية عبر واجهة دردشة ذكية تعتمد على تقنيات الذكاء الاصطناعي. يستطيع الموقع الإجابة تلقائياً على استفسارات الطلاب حول معلومات الكلية، الهيكل الإداري، تفاصيل الأقسام، الساعات والجداول الدراسية، بالإضافة إلى توفير معلومات شاملة تساعد الطلاب على الحصول على ما يحتاجونه بسرعة ودقة.

---

## 🚀 الميزات الرئيسية

- دردشة تفاعلية ذكية تعتمد على الذكاء الاصطناعي للرد على استفسارات الطلاب.
- تغطية شاملة لمعلومات الكلية، الهيكل الإداري، الأقسام، الساعات والجداول الدراسية.
- تحديث مباشر ومستمر لقاعدة المعرفة لضمان دقة المعلومات.
- واجهة مستخدم سهلة الاستخدام ومتجاوبة مع تصميم احترافي باستخدام MudBlazor.
- دعم تسجيل الدخول والمستخدمين (إن كنت تخطط لذلك).
- استضافة آمنة وسريعة على خدمات سحابية مثل Azure.

---

## 🧑‍💻 التقنيات المستخدمة
| التقنية      | الاستخدام                                                    |
|--------------|-------------------------------------------------------------|
| Blazor server| بناء البنية الأساسية للموقع وتطوير واجهات المستخدم            |
| MudBlazor    | تصميم وتنسيق واجهات المستخدم بأسلوب احترافي ومتجاوب           |
| GeminiApi    | خدمة الإجابة التلقائية على أسئلة الطلاب بناءً على قاعدة المعرفة |
| C#           | لغة البرمجة الأساسية في تطوير المنطق الخلفي للتطبيق          |
| SQL Server   | تخزين وإدارة بيانات الكلية والجداول الدراسية                |
| Azure        | استضافة التطبيق وتوفير البنية التحتية السحابية              |
