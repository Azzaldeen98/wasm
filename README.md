# موقع دردشة الي بالذكاء الاصطناعي 

عباره عن موقع دردشة خاص بكلية الخرمة التطبيقية  يجيب بشكل تلقائي على اسئلة الطلاب حول الكلية والهيكل الاداري ومعلومات الاقسام  والساعات الدراسية  والجداول الدراسية  ومعلومات عن الكلية  

---

## 🚀 الميزات الرئيسية

- الاجابه على الاسئلة المتعلقة بالكلية والهيكل التنظيمي والاداري
- الاجابه على الاسئلة المتعلقة بالمكأت الدراسية 
- الاجابة على الاسئلة والقوانين الخاصه بالكلية 

---

## 🧑‍💻 التقنيات المستخدمة
|---------|-----------|
|C# | لغة البرمجة المستخدمه |
|Blazor| إطار العمل  المستخدم   (Frameworks) |
|MudBlazor | تصميم واجهات المشروع |
|SQL Server | قاعدة بيانات لتخزين معلومات المستخدمين  وقاعدة المعرفة الخاصه بالكلية  |
|GeminiApi |  استخلاص الرود والاجابات على الاسئلة التي يطرحها المستخدم من قاعدة المعرفة واعادة توليدها وصياغتها بالشكل المطلوب   |
